# KubeOps

KubeOps is a Kubernetes Deployment Management and Monitoring Platform.

## Project Overview

A centralized platform designed to manage and monitor Kubernetes workloads.

## Planned Features

- Kubernetes namespace monitoring
- Pod and deployment monitoring
- Deployment scaling
- Rolling restarts
- Pod log retrieval
- Kubernetes event monitoring
- Prometheus and Grafana integration
- Role-Based Access Control (RBAC)

## Technology Stack

- Java 21
- Spring Boot
- React
- Kubernetes
- Docker
- Helm
- Prometheus
- Grafana
- GitHub Actions
- Terraform
